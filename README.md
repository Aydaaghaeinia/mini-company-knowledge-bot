# 🤖 Mini Company Knowledge Bot

این پروژه یک سیستم پرسش‌وپاسخ (RAG) هوشمند و مینیمال است که به عنوان چالش عملی برای ورود به فصل صفر (Season 0) برنامه **Soli AI Builders Lab** توسعه داده شده است.

## 🎯 هدف پروژه
این سیستم فایل‌های متنی و PDF سازمان را از پوشه `data/` خوانده و به سؤالات کاربران پاسخ می‌دهد. 
**قانون سخت‌گیرانه (Strict Boundary):** خروجی صرفاً بر اساس فایل‌های موجود است و در صورت عدم وجود اطلاعات، سیستم صراحتاً اعلام می‌کند: «نمی‌دانم، در فایل‌های موجود پاسخی برای این سوال نیست.» (بدون هیچ‌گونه توهم یا Hallucination).

## 🛠️ پشته فناوری (Tech Stack)
به دلیل ناپایداری برخی محیط‌های ابری و برای داشتن یک سیستم کاملاً مستقل و قابل اجرا به صورت Local، معماری زیر پیاده‌سازی شده است:
- **فریم‌ورک هوش مصنوعی:** LangChain
- **پایگاه داده برداری:** FAISS (اجرای سریع و درون‌حافظه‌ای)
- **مدل Embedding:** `intfloat/multilingual-e5-small` (پشتیبانی عالی از فارسی و انگلیسی)
- **مدل زبانی (LLM):** `Qwen/Qwen2.5-0.5B-Instruct` (اجرای محلی با HuggingFace Pipeline)
- **بک‌اند:** FastAPI
- **رابط کاربری:** Streamlit

## 🤖 ابزارهای AI استفاده شده در توسعه
برای توسعه سریع‌تر و دیباگ این پروژه، از ترکیب ابزارهای زیر استفاده شده است:
- **ChatGPT:** برای طراحی ساختار اولیه پوشه‌ها و معماری فایل‌ها.
- **Claude:** برای نگارش لاجیک اصلی RAG و Refactoring نهایی کدها.
- **Gemini:** برای دیباگینگ مسیرهای دارای خطا و توسعه رابط کاربری با Streamlit.
- **DeepSeek:** برای مطالعه دقیق اسناد تست و استخراج سوالات ارزیابی (`EVALS.md`).

*(نکته: با ابزارهایی نظیر Cursor و GitHub Copilot آشنایی کامل وجود دارد، اما برای حفظ تمرکز روی لاجیک اصلی و جلوگیری از تولید فایل‌های اضافی، در این تسک از آن‌ها استفاده نشده است.)*

## 🚀 راهنمای نصب و اجرا

### ۱. نصب پیش‌نیازها
ابتدا یک محیط مجازی (Virtual Environment) بسازید و کتابخانه‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
۲. قرار دادن داده‌ها
فایل‌های .md یا .pdf خود را داخل پوشه data/ قرار دهید.

۳. اجرای سرور بک‌اند (FastAPI)
در یک ترمینال، دستور زیر را برای اجرای موتور پردازشی RAG وارد کنید:

Bash
python main.py
(سرور روی http://127.0.0.1:8000 اجرا خواهد شد)

۴. اجرای رابط کاربری (Streamlit)
در یک ترمینال دیگر، رابط کاربری چت‌بات را اجرا کنید:

Bash
streamlit run app.py
سپس می‌توانید در مرورگر خود با بات گفتگو کنید.
