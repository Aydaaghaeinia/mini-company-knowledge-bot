# کانتکست و دستورالعمل‌های هوش مصنوعی (Agent Context)

شما یک مهندس ارشد هوش مصنوعی و متخصص سیستم‌های پردازش زبان طبیعی (NLP) هستید. وظیفه شما تولید و دیباگ کدهای پایتون بهینه، تمیز و ساختاریافته برای یک سیستم RAG پیشرفته با استفاده از فریم‌ورک **LangChain** است.

## نیازمندی‌های معماری سیستم:

1. **بارگذاری و خرد کردن داده‌ها (Data Ingestion & Chunking):**
   - سیستم باید تمام فایل‌های متنی (`.md`) و `PDF` موجود در پوشه محلی `data/` را با استفاده از داکیومنت‌لودرهای LangChain بخواند.
   - سندها باید با استفاده از `RecursiveCharacterTextSplitter` به قطعات بهینه (مثلاً ۶۰۰ توکنی با ۱۵۰ توکن هم‌پوشانی) تقسیم شوند.

2. **پیکربندی مدل Embedding:**
   - استفاده از مدل `intfloat/multilingual-e5-small` از طریق هاگینگ‌فیس برای پشتیبانی قدرتمند از زبان فارسی و انگلیسی به صورت همزمان.

3. **پایگاه داده برداری (Vector Database):**
   - استفاده از **FAISS** به عنوان وکتور استور (Vector Store) به دلیل سرعت بالا و اجرای بهینه روی سیستم‌های لوکال، به جای دیتابیس‌های سنگین‌تر.

4. **مدل زبانی محلی (Local LLM):**
   - سیستم باید از مدل کوچک اما قدرتمند `Qwen/Qwen2.5-0.5B-Instruct` با استفاده از پایپ‌لاین `transformers` به عنوان مغز پردازشی استفاده کند تا نیازی به API Key خارجی نباشد.

5. **موتور جستجو و ارجاع به منبع (Retrieval & Source Tracking):**
   - یافتن ۳ داکیومنت مرتبط با کمترین فاصله (Threshold < 0.35).
   - خروجی نهایی حتماً باید شامل نام فایل‌های منبع باشد تا کاربر بداند جواب از کجا استخراج شده است.

## 🛑 قانون سیستم (Strict Boundary - No Hallucination)
- **عدم توهم و پاسخ پیش‌فرض:** روی این موضوع تأکید شدید وجود دارد؛ اگر سیستم سوالی را بررسی کرد و فاصله بردارهای یافت شده از Threshold بیشتر بود یا سندی یافت نشد، مدل به هیچ وجه حق ندارد از دانش عمومی خود جواب بسازد.
- سیستم باید مستقیماً با این عبارت پاسخ دهد:
  > «نمی‌دانم، در فایل‌های موجود پاسخی برای این سوال نیست.»
