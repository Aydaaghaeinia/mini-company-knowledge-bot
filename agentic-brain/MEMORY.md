# حافظه و تصمیمات پروژه (Project Memory & Architecture Log)

## 📍 وضعیت فعلی پروژه
- **مرحله:** توسعه سیستم RAG محلی، راه‌اندازی API با FastAPI و رابط کاربری با Streamlit تکمیل شد.
- **مخزن:** ریپازیتوری نهایی شده و کدهای فرانت‌اند و بک‌اند متصل هستند.

## 🛠️ تصمیمات معماری سیستم (Architectural Decisions)

1. **تغییر فریم‌ورک از LlamaIndex به LangChain:**
   - **علت تصمیم:** در ابتدا قصد داشتیم از LlamaIndex استفاده کنیم، اما به دلیل ناپایداری‌های محیط کولب و محدودیت‌ها در هندل کردن منعطف پایپ‌لاین‌ها، تصمیم گرفتم پروژه را به **LangChain** مهاجرت دهم. این کار کنترل بیشتری روی Prompt Formatting و Retrieval به من داد.

2. **استفاده از FAISS به جای ChromaDB:**
   - **علت تصمیم:** برای یک سیستم Mini Knowledge Bot که قرار است سبک و سریع باشد، پردازش درون‌حافظه‌ای FAISS پرفورمنس بسیار بهتری نسبت به راه‌اندازی ChromaDB روی سیستم‌های با منابع محدود داشت.

3. **انتخاب مدل Qwen 0.5B:**
   - **تصمیم فنی:** به جای استفاده از APIهای پولی (مثل OpenAI)، برای نشان دادن توانمندی سیستم‌های Agentic محلی، مدل Qwen 0.5B انتخاب شد که هم در زبان فارسی عملکرد قابل قبولی دارد و هم روی سخت‌افزار معمولی اجرا می‌شود.

4. **اضافه کردن Streamlit به عنوان رابط کاربری (UI):**
   - **تصمیم فنی:** با وجود اینکه تسک فقط یک Endpoint ساده با FastAPI می‌خواست، برای تجربه کاربری (UX) بهتر و دمو کردن راحت‌تر سیستم، یک رابط کاربری مینیمال با Streamlit توسعه داده شد.
